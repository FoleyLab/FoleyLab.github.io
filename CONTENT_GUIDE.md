# Foley Lab Website Content Guide

Most updates now happen by adding or editing small Markdown files.

## Add a person

1. Create a new file in `_people/`.
2. Copy one of the existing files and update:
   - `name`
   - `role`
   - `status` as `current` or `alumni`
   - `image`
   - `email`
   - `research_focus`
   - `education`
3. Add a short paragraph below the front matter.

## Add a publication

1. Create a new file in `_publications/`.
2. Include:
   - `title`
   - `date`
   - `journal`
   - `authors`
   - `external_url`
   - `toc_figure`
   - `abstract`
3. Optionally add extra notes or highlights below the front matter.

### BibFinder export workflow

The Foley Lab bibliography repository can generate publication entries for Jonathan/Foley papers:

```bash
python3 bibfetch.py export-site master.bib \
  --website-repo /Users/jfoley19/Code/FoleyLab.github.io
```

Generated files are named `bibfinder-<BibTeX key>.md`. Hand-authored entries are preserved, while entries previously generated by BibFinder are refreshed. The command also writes `bibfinder_toc_manifest.csv`, which lists the expected TOC image path for every selected publication.

Place downloaded TOC images at `images/publications/<BibTeX key>.png` and rerun the exporter. The generated publication file will then include its `toc_figure` field. The exporter does not scrape or download publisher images automatically.

## Add a news item

1. Create a new file in `_news/`.
2. Include:
   - `title`
   - `date`
   - `image`
3. Write the news item body below the front matter.

## Add images

- Put images in `images/`.
- Reference them as `/images/filename.png` in front matter.

## Research software

- The software showcase page lives at `software.md`.
- Project entries live in `_software/`.
- Add one Markdown file per project with `title`, `section`, `order`, `project_url`, `summary`, optional `meta`, optional `initials`, and optional `logo`.
- The reusable card markup lives in `_includes/software-card.html`.
- Styling for the current site design lives in `assets/css/foleylab.css`.
